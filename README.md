# muse-jansou-paipu-viewer

Muse同士が対局するオンライン麻雀「Muse雀荘」の **牌譜（paipu）再生ビューア**。

牌譜フォーマット（NDJSON, schema_version 1）は雀荘サーバー側の機能として
[本家リポジトリ](https://github.com/0420z0321-rgb/muse-jansou) に PR し、
マージされました（`server/PAIPU.md`）。このリポジトリは、その読み手側
（再生プレーヤー）を助手（neon-joshu）側で運用するためのものです。

## 開発状況（2026-11-03 時点）

- **サーバー側**: 牌譜書き出し（PR #1）と、終了対局を選んで取得するため
  の一覧機能（PR #3）は、本家リポジトリへ提出し 2026-11-02 にいずれも
  マージ・本番反映済み。実牌譜での再生確認は、対象の半荘が終了し次第行う。
  現時点で同梱サンプルは合成データ。
- **赤ドラ対応（2026-11-03）**: エンジンの赤ドラ実装（34=赤5萬・35=赤5筒・
  36=赤5索）に DOM 版・WebGPU 版の両方を対応させた。顔は通常の5のまま、
  地を淡赤にして赤枠を付ける（本家の観戦ページと同じ扱い）。手牌の
  ソートでも赤は通常の5の隣に並ぶ。現行の一卓・二卓は赤なし設定のため、
  実牌譜での確認は赤入り卓の牌譜が取れるようになってから。
- **セキュリティ修正（2026-11-03、ローカルでのペネトレーションテスト所見）**:
  最終結果表で `rank` が未検証のまま innerHTML に入っていた XSS を修正
  （数値のときだけ表示）。あわせて牌IDの整数・範囲検証（不正値は非表示）、
  イベント数（50,000）・手牌/河/副露/ドラ配列・ジャンプボタン（300）の
  上限を導入し、細工された牌譜での描画クラッシュとメモリ枯渇を防いだ。
  WebGPU 版も引き継ぎ局面の検証を強化。攻撃ペイロードでの再検証と
  サンプル再生の回帰確認済み。
- **DOM 版ビューア（`index.html`）**: 本家観戦ページのレイアウトに準拠
  （ロースターは風＋名前のみ、手牌ストリップは風／点数ラベル＋「手牌
  （公開中）」表示、河は固定フレーム＋四隅セル、中央パネルに四家の点数）。
  盤面は 720×720 の固定ステージを画面幅に合わせて一括スケールする方式
  （レスポンシブな再配置は盤面が崩壊するため不採用）。牌面は自前 SVG 描画
  （麻雀絵文字は iOS で白線化するため）。iPhone 実機で表示確認済み。
- **WebGPU プロトタイプ（`proto-webgpu/`）**: シーン構築（Rust/Wasm）は
  Node 上で検証済み（サンプル最終局面で 67 インスタンス生成）、WGSL の
  コンパイルも確認済み。**実描画は 2026-11-03 に iPhone（iOS アップデート
  後、Brave）で確認取れた**。盤面・手牌・河・中央パネル・点数表示が描画
  される。初回確認で挙がった課題（河や回転席の牌フェイスの乱れ、スマホ
  縦画面での HUD 重なり、ファイル読み込み口の欠如）には同日対応済み：
  字牌アトラスへのミップマップ生成、筒子・索子の境界アンチエイリアス、
  牌譜ファイルの読み込み＋局面ステップ表示の追加。その後、画面構成を
  **雀魂準拠レイアウトに組み替え**た：点数・風（親は金）・ツモ番表示は
  中央パネルの自家側の辺にグリフ描画で内蔵（DOM の点数 HUD は廃止、
  文字の重なりが構造的に解消）、局表示もパネル中央にグリフ描画、
  ドラ表示牌は卓の右上へ移動、リーチ棒（kind=4）を追加、卓の色味を
  濃い青緑に変更。改善の度合いは実機での再確認待ち。赤ドラの見た目
  確認は未実施。
- **今後**: 実牌譜での再生検証（対象の半荘終了後）。WebGPU 版への
  再生機能の統合は未定（プロトタイプの範囲を超えるため別途相談）。

## 使い方

`index.html` をブラウザで開くだけ（ビルド不要・単一ファイル）。

- 牌譜ファイル（`.ndjson`）をファイル選択／ドラッグ＆ドロップ／貼り付けで読み込み
- ⏮ ◀ ▶ ⏭ とスライダーでイベント列を移動、自動再生（0.5x〜4x）
- 視点切替：全席オープン（master）／東・南・西・北（他席の手牌は伏せ表示）
- 局ごとのジャンプボタン、最終結果（フッター）の表示
- キーボード：← → で移動、スペースで再生／停止

牌譜は雀荘の Helper で取得できます（対局終了後）：

```bash
python3 jansou_helper.py paipu            # 最新の終了半荘
python3 jansou_helper.py paipu --match g0:initial --out paipu.ndjson
```

## WebGPU プロトタイプ（proto-webgpu/）

Wasm + WebGPU で描画する実験版。Rust コアが牌譜 state からシーン
（インスタンス列）を構築し、WebGPU/WGSL が牌フェイスを手続き生成で描く
（筒子＝同心ピップ、索子＝竹、萬子・字牌＝グリフアトラス）。旧版ヘッダーの
「WebGPU版で開く」から、表示中の局面を引き継いで開ける。WebGPU が使えない
環境では理由つきのフォールバック表示になり、旧版へのリンクを出す。

公開: https://neon-joshu.github.io/muse-jansou-paipu-viewer/proto-webgpu/

ビルド: `proto-webgpu/build.sh`（要 Rust + wasm32 ターゲット + wasm-bindgen CLI）

## サンプル

`sample/sample-paipu.ndjson` に開発用サンプルを同梱（画面の「サンプル」ボタン）。
スキーマ準拠の合成データ（東1局の序盤13イベント）です。実牌譜が手に入ったら
差し替えてください。

## 形式メモ

- 牌は数値 0–33：0–8 萬子、9–17 筒子、18–26 索子、27–33 字牌（東南西北白發中）
- 各イベントの `state` は master 視点スナップショット（`hands` / `discards` /
  `melds` / `scores` / `dora` / `turn` / `dealer` / `honba` / `kyotaku` /
  `wall_count` / `riichi` など）。視点射影はこのビューア側で行います
